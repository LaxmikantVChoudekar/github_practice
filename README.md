# github_practice

A repository created for practicing **Git** and **GitHub** commands.

## 🎯 Purpose
- Learn and experiment with Git basics (init, add, commit, push, pull).
- Practice branching, merging, and resolving conflicts.
- Explore GitHub features like issues, pull requests, and README formatting.

## 📚 Topics Covered
- Creating repositories
- Making commits
- Pushing and pulling changes
- Working with branches
- Using GitHub GUI and CLI
- Writing Markdown files
